## 什么是计算机技术

计算机技术就是用计算机来解决问题的技术。从最简单的"1+1=2"到复杂的人工智能，都是计算机技术的范畴。它不仅仅是写代码，还包括计算机原理、操作系统、网络、数据库、安全等方方面面。

## 我在学什么

作为一个软件学院的学生，我目前在学这些东西：

### 编程语言

编程语言是人和计算机沟通的语言。我们用编程语言告诉计算机要做什么。

**C 语言**

C 语言是最基础的编程语言，也是很多大学的入门语言。它的特点是：

- **贴近硬件**：可以直接操作内存地址，理解计算机底层是怎么工作的
- **指针**：C 语言最核心也最难的概念，指针就是内存地址
- **效率高**：C 语言写的程序运行速度很快，操作系统、编译器很多都是用 C 写的
- **应用广泛**：嵌入式、驱动、操作系统底层都用 C 语言

学 C 语言最重要的是理解内存——栈、堆、全局区、代码区，数据在内存里是怎么存储的。

**Java**

Java 是面向对象编程语言的代表。它的特点是：

- **跨平台**：一次编写，到处运行（JVM 虚拟机）
- **面向对象**：一切都是对象，有封装、继承、多态三大特性
- **自动垃圾回收**：不用手动管理内存，JVM 自动回收
- **应用广泛**：安卓开发、后端服务、大数据都用 Java

Java 的核心是面向对象思想——把现实世界的事物抽象成类和对象。比如"猫"是一个类，"我家的猫"就是一个对象。

**Python**

Python 是现在最火的编程语言之一，特点是简单易学：

- **语法简洁**：代码像伪代码一样，读起来像英语
- **库丰富**：数据分析、人工智能、Web 开发、爬虫，什么都能做
- **入门友好**：适合编程零基础的人入门

Python 是"胶水语言"——它可以把其他语言写的东西粘在一起。现在人工智能这么火，Python 功不可没。

### 数据库

数据库是存储数据的地方。我们的用户信息、文章、评论，都存在数据库里。

**MySQL**

MySQL 是最常用的关系型数据库。关系型数据库就是用表来存储数据，像 Excel 表格一样。

核心概念：
- **表（Table）**：一张二维表，每行是一条记录，每列是一个字段
- **SQL**：结构化查询语言，用来操作数据库
- **索引**：给表加索引，查询速度会快很多

常用操作：
- **增**：INSERT INTO users (name, age) VALUES ('小明', 20)
- **删**：DELETE FROM users WHERE id = 1
- **改**：UPDATE users SET age = 21 WHERE id = 1
- **查**：SELECT * FROM users WHERE age > 18

学数据库最重要的是理解表设计——怎么设计表结构，怎么建立表之间的关系。

### Web 开发

Web 开发就是做网站，分为前端和后端。

**前端**

前端就是用户在浏览器里看到的东西：

- **HTML**：网页的骨架，定义页面有什么内容
- **CSS**：网页的样式，定义页面长什么样（颜色、布局、字体）
- **JavaScript**：网页的行为，定义页面怎么交互（点击按钮、动画、表单验证）

现在前端有很多框架，比如 Vue、React，让开发更高效。

**后端**

后端就是服务器上跑的程序，处理业务逻辑：

- **Java Web**：用 Java 写后端接口
- **接口（API）**：前端和后端沟通的方式，前端发请求，后端返回数据
- **RESTful API**：一种接口设计风格，用 HTTP 方法表示操作（GET 查询、POST 新增、PUT 修改、DELETE 删除）

后端的核心是业务逻辑——用户注册、登录、发文章、评论，这些都是后端处理的。

### 安全

安全就是保护系统不被攻击。作为一个对安全感兴趣的人，我在学：

**渗透测试**

渗透测试就是模拟黑客攻击，找出系统的漏洞，然后修复它。

- **黑盒测试**：不知道系统内部结构，像黑客一样从外部攻击
- **白盒测试**：知道系统源码和结构，内部审计
- **灰盒测试**：介于两者之间

**Kali Linux**

Kali Linux 是专门的渗透测试系统，里面预装了几百种安全工具：

- **信息收集**：Nmap 端口扫描、域名枚举
- **漏洞利用**：Metasploit 漏洞利用框架
- **密码攻击**：Hydra 暴力破解、John the Ripper 密码破解
- **Web 安全**：Burp Suite、SQLmap

**Burp Suite**

Burp Suite 是 Web 安全最常用的工具：

- **抓包**：拦截浏览器和服务器之间的请求
- **改包**：修改请求参数，测试漏洞
- **重放**：重复发送同一个请求
- **扫描**：自动扫描常见漏洞

## 学习心得

计算机技术看起来很难，但其实就是**不断解决问题**的过程。遇到 bug 不要怕，一步一步调试，总能找到问题在哪。

最重要的不是记住多少语法，而是学会**怎么思考问题**——把一个大问题拆成一个个小问题，然后逐个解决。

学习编程没有捷径，就是多写多练。看十遍不如写一遍，写十遍不如踩一遍坑。踩的坑多了，自然就会了。

## 结语

路漫漫其修远兮，吾将上下而求索。技术这条路很长，慢慢学，慢慢来。不积跬步，无以至千里；不积小流，无以成江海。
