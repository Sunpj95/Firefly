## 什么是计算机技术

计算机技术就是用计算机来解决问题的技术。从最简单的"1+1=2"到复杂的人工智能，都是计算机技术的范畴。

## 我在学什么

作为一个软件学院的学生，我目前在学这些东西：

### 编程语言

- **C 语言**：最基础的编程语言，理解内存和指针
- **Java**：面向对象编程，安卓开发基础
- **Python**：简单易用，做脚本和数据分析

### 数据库

- **MySQL**：最常用的关系型数据库，存储数据

### Web 开发

- **HTML/CSS/JS**：网页三剑客
- **Java Web**：用 Java 写后端接口

### 安全

- **渗透测试**：学习 Web 安全，找漏洞
- **Kali Linux**：渗透测试专用系统
- **Burp Suite**：抓包改包工具

## 学习心得

计算机技术看起来很难，但其实就是**不断解决问题**的过程。遇到 bug 不要怕，一步一步调试，总能找到问题在哪。

最重要的不是记住多少语法，而是学会**怎么思考问题**——把一个大问题拆成一个个小问题，然后逐个解决。

## 结语

路漫漫其修远兮，吾将上下而求索。技术这条路很长，慢慢学，慢慢来。
